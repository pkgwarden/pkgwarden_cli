# Security policy

## Reporting a vulnerability

Email **security@pkgwarden.com** with a description of the issue, the affected `pw` version
(`pw --version`), and the steps needed to reproduce it. Please do not open a public issue for a
suspected vulnerability, and please do not disclose it publicly until we have had a chance to
respond.

We acknowledge reports within 3 business days and will keep you updated while we investigate and
prepare a fix.

## Scope

This repository contains the pkgwarden CLI (`pw`). Vulnerabilities in the hosted pkgwarden
service, the gate, or the web application belong at the same address; say which surface is
affected so we can route the report.

## Bounty

We do not run a bug bounty program today. We are grateful for reports regardless, and we are happy
to credit you when we publish a fix if you would like us to.
